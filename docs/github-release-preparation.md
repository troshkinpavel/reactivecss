## 2. Security

Two read-only scans (file names and contents, including `dist/*.js`, source maps, fixtures, docs, `site/config`, `site/admin`, `benchmarks`, `experiments`, `.claude`, `.github`):

- **No secrets found.** No npm, GitHub, AWS, Cloudflare, Slack or Stripe tokens, no private keys, no JWTs, no `.env`, `.npmrc`, `.netrc`, database or cookie files.
- The admin test token in `site/tests/unit/admin-server.test.ts` is a dummy value. `site/admin/index.html` has a placeholder that the local server fills at runtime.
- **Local paths:** none in files that are uploaded. The source maps use relative paths. `.idea/workspace.xml` and `experiments/.out` have local paths and are ignored.
- **Personal data:** no email address of the owner. The only handle is `troshkinpavel` in the package URLs (intended).
- **Control Center** (`site/admin/server.ts`): binds to 127.0.0.1, checks the Host header and `Sec-Fetch-Site`, uses a random per-run token, writes only to `site/config/<known>.json` after schema validation. It has no stored secret and is never built into the site.
- **`site/config/`:**
  - Public build-time settings: `seo.json`, `links.json`, `features.json`, `announcements.json`.
  - Local operational data: `project.json` (admin UI preferences, not read by the site).
  - Mixed: `releases.json`. Its `notes` and `workflow` fields are internal and are stripped from the site build (verified: no hits in `site/dist`), but they are readable in the repository.
- Info: `build.mjs --serve` and `site/scripts/serve-static.mjs` listen on all interfaces (static files only, development).

Exclusions applied: see `.gitignore`. Nothing was deleted or overwritten. No rotation is needed: no credential was found.
