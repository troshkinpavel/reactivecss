Reactive CSS · Demos

CSS that reacts

State, events and DOM bindings written in CSS. Each demo has no JavaScript of its own.

  • 01

    Counter

    A number that buttons change, with real disabled buttons at the limits.

    state() :on(click) content --attr-disabled

  • 02

    Tabs

    Click or arrow keys. One state drives the tabs, the panels and the ARIA attributes.

    :nth-var() cycle() prevent() focus

  • 03

    Drag

    A card that follows the pointer and stays inside its area. Arrow keys move it too.

    :on(drag) event(x) element() clamp()

  • 04

    Accordion

    Items that open on their own, with an animated height and aria-expanded.

    toggle() when() --attr-aria-expanded

  • 05

    Context Menu

    A right-click menu that opens where you click, stays inside the desk and closes on Escape or outside.

    :on(contextmenu, prevent()) event(local-x) outside() focus

  • 06

    Theme

    Color scheme and accent for the whole page, kept across reloads.

    persist() :root light-dark() --attr-aria-pressed

  • 07

    Profile Builder

    A form that updates a live card: text, select, range and checkbox, with a check on blur.

    event(value) event(checked) :on(reset) :blur

  • 08

    Spotlight

    Cards with a glow and a lit border that follow the pointer.

    mouse(x, local) radial-gradient()

  • 09

    Palette

    Random palettes with a name on every click, and blobs that drift on their own.

    random() pick() live()

  • 10

    History

    A value that knows what it was and which way it moved.

    previous() direction() :changed()

  • 11

    Scroll Reveal

    Steps that fade in as they scroll into view, with a native scroll progress bar.

    visible() animation-timeline

  • 12

    Task List

    Each task owns its state and the list counts them, with a progress bar and a finish line.

    nested state :when(not …) :just-checked
