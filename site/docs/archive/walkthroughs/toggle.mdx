## How it works
1. `--on: state(false)` gives each switch its own boolean.
2. `on: click(toggle(--on))` flips it.
3. Two `when()` declarations read it. Because both are boolean conditions with static values, they compile to native `if()` where supported.

## Compared with JavaScript
The JavaScript version keeps the state in `aria-checked` and lets CSS style `[aria-checked="true"]`. That is a good pattern, and the attribute is the accessible state.

## Accessibility
<Callout kind="warning" title="Visual only">

`aria-checked` doesn't change. The library's own playground uses a native `<input type="checkbox" role="switch">` with `bind: --on` instead, which is complete.

</Callout>
