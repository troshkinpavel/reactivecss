## How it works
1. Three states on `.signup` hold the name, plan and newsletter choice.
2. `bind:` connects each native control to its state in both directions.
3. The preview reads them with `var()` and `:when()`. Strings read as quoted CSS strings, so `content: var(--name)` prints them.

## Compared with JavaScript
The JavaScript version reads the whole form with `FormData` on each input event, which scales well to many fields. The Reactive CSS version needs a state per field but no event wiring.
