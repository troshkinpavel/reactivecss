## How it works
1. `previous()` and `direction()` read the state's history.
2. `.counter:changed(--count) output` matches after each change until its animation finishes.
3. `when(direction(--count) > 0, …)` picks the keyframes.

## Compared with JavaScript
The JavaScript version restarts the animation by removing the class, forcing a reflow with `offsetWidth` and adding it back.

<Callout kind="tip" title="Reduced motion">

Disable the animation under `prefers-reduced-motion: reduce`. See [State History](/docs/history/).

</Callout>
