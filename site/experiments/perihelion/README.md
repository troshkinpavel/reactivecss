# 001 · Perihelion · motion card

A foil collector card: 3D tilt, trailing specular light, parallax layers and a spring return. Card 07 of 24 of an invented series, "Lumen Atlas": a planet at its closest pass to its sun.

- **Live:** [reactivecss.com/experiments/perihelion/](https://reactivecss.com/experiments/perihelion/) (after the website is published).
- **Files:** `index.html` (markup) and `style.css` (everything else). There is no application JavaScript. The only script is the Reactive CSS 0.9.0 runtime.
- **Run it locally:** in `site/`, run `npm run dev`, then open `http://localhost:4321/experiments/perihelion/`. The site serves this folder as `/embed/experiments/perihelion.stage.html` and `perihelion.card.html` (generated by `scripts/sync-runtime.mjs`). To use the files elsewhere, point the `<script>` in `index.html` at your copy of `reactive-css.min.js`.

## Interaction

| Input | Result |
|---|---|
| Pointer over the card | It lifts and tilts toward the pointer, up to 18° on Y and 14° on X. Each layer parallaxes by its depth. The specular and edge light follow about 170 ms behind. The foil brightens toward the edges. The floor shadow moves away. |
| Pointer leaves | The card springs back to rest in 1.15 s, with a `linear()` damped-spring easing. |
| Click, tap, Enter or Space (a real `<button>`) | The next edition: Aurora → Gilt → Nocturne. The colours cross-fade, and one light sweep crosses the card. |
| Keyboard focus | A presentation pose with a slow glint. |
| Foil range | Scales the foil and the glitter, from matte (0) to full (100). |
| Reduced motion | No tilt, parallax, sweeps or colour transitions. The light, the foil and the editions still respond. |

## Reactive CSS

| API | Use |
|---|---|
| `state()` | `--edition` and `--foil` on the stage, `--hot` on the slot |
| `mouse(x, local)`, `mouse(y, local)` | The pointer inside the slot, a wrapper that is never transformed |
| `element(width)`, `element(height)` | The slot's size, to normalise the pointer to −1..1 |
| `:on(pointerenter)`, `:on(pointerleave)` | Hover as a state, so a tap on a touch screen never leaves the card tilted |
| `:on(click)` with `cycle()` | The edition |
| `:on(input)` with `event(value-as-number)` | The range writes the stage's `--foil` |
| `content: var(--edition)` | The edition name, as DOM text in a live region |
| `:when()` | The tracking pose, the editions and the indicators |
| `:changed(--edition)` | One light sweep per edition change |

Everything else is native CSS: registered custom properties (`@property`), 3D transforms, transitions with a `linear()` spring, gradients, masks, blend modes, container units and `color-mix()`.

## Changes from the Visual Lab version (Reactive CSS 0.8)

The artwork and the behaviour are unchanged. The 0.8 declarations were rewritten in the 0.9 language:

| 0.8 | 0.9 |
|---|---|
| `.card { on: click(cycle(--edition, aurora, gilt, nocturne)); }` | `.card:on(click) { --edition: cycle(aurora, gilt, nocturne); }` |
| `.slot { on: pointerenter(set(--hot, true)), pointerleave(set(--hot, false)); }` | `.slot:on(pointerenter) { --hot: set(true); }` and `.slot:on(pointerleave) { --hot: set(false); }` |
| `.foil-range { bind: --foil; }` | `.foil-range:on(input) { --foil: set(event(value-as-number)); }`: the range is a sibling of the card, so it writes the stage's state rather than owning one with `bind()` |
| `.ed-name { text: var(--edition); }` | `.ed-name { content: var(--edition); }` |

The harness loader of the lab was replaced by the runtime's own script tag. A block at the end of `style.css`, under `:root[data-embed]`, lays the card out for the website's frames.

## Browsers

Tested in Chromium and WebKit (Playwright engine builds), with the site's tests in `site/tests/e2e/experiments.spec.ts`. Firefox is not verified. Real touch devices are not verified.

## Assets

Everything is procedural CSS. There are no images and no web fonts: the card uses system fonts (Didot or Bodoni with serif fallbacks, and Avenir Next with sans-serif fallbacks), so its type differs on systems that do not have them.
